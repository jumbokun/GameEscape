## Play in the browser

`web/index.html` is a canvas port of the game with every asset inlined.
Download it and open it in any browser: Space, Up or a tap jumps, P pauses.

To rebuild it from the original sources:

```
unzip Escape.zip
pip install fonttools
python web/build.py Escape/src
```
